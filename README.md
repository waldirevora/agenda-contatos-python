# Agenda de Contatos em Python

Projeto desenvolvido para praticar fundamentos da linguagem Python durante os estudos na Rocketseat.

A aplicação funciona no terminal e permite cadastrar, listar, editar, favoritar e excluir contatos.

## Funcionalidades

- Adicionar contato
- Listar contatos
- Editar contato
- Marcar ou desmarcar contato como favorito
- Listar contatos favoritos
- Apagar contato
- Salvar contatos em arquivo JSON
- Carregar contatos salvos ao iniciar o programa
- Tratamento básico de entradas inválidas

## Como executar

Clone o repositório:

```bash
git clone https://github.com/waldirevora/agenda-contatos-python.git
```

Entre na pasta do projeto:

```bash
cd agenda-contatos-python
```

Execute a aplicação:

```bash
python app.py
```

## Estrutura do projeto

```text
agenda-contatos-python/
├── app.py
├── .gitignore
└── README.md
```

O arquivo `contatos.json` é criado automaticamente durante o uso da aplicação e permanece apenas no ambiente local.
